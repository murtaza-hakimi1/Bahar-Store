# Bahar Store

A responsive Persian/English fashion storefront built with React, Vite, Tailwind CSS and Framer Motion. Includes a product catalogue, local cart, demo checkout/tracking, theme toggle, a three-slide animated hero, and a contact form backed by an Express API that emails the store owner.

## Requirements

- Node.js 18 or newer
- An SMTP mailbox for the store (for example, Gmail with an app password)


```
